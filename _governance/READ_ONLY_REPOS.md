# REGRA ABSOLUTA: Repositorios/ É SOMENTE LEITURA

## Princípio
`Repositorios/` é a **fonte imutável de verdade**. Ninguém — nem leads, nem funcionários, nem o líder — escreve, apaga ou modifica nada lá dentro.

## O que PODE
- Ler arquivos para extração
- Copiar trechos para citação em extrações
- Referenciar paths em documentos de consolidação

## O que NÃO PODE
- Criar, editar, deletar arquivos ou pastas
- Renomear repositórios
- Mover conteúdo para fora (exceto leitura)
- Commits/git operations dentro de Repositorios/

## Onde ESCREVER
Cada lead escreve **exclusivamente** em sua pasta de trabalho:
```
_consolidado/agents/{lead}/extractions/
_consolidado/agents/{lead}/CONSOLIDATED.md
_consolidado/agents/{lead}/{domain-specific-folders}/
```

O líder (Severino) consolida em:
```
_consolidado/cross-cutting/
```

## Sanção
Qualquer violação = reversão imediata + revisão de processo.
