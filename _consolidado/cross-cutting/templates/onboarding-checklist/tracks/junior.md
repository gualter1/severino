# Trilha Junior (Semanas 1-4) — 0-2 anos

**Objetivo**: executar com autonomia supervisionada. Sair bootando, testando, commitando e abrindo PRs limpos.

| Semana | Foco | Entregável | Validação |
|--------|------|------------|-----------|
| 1 | Fundamentos (`checklist.md` dias 1-5) | First PR merged + retro | Grill-me S1-S5 |
| 2 | Testes AAA + style | 1 feature mock com 80/70 coverage | Qualy review + CI gate |
| 3 | Feature real pequena (bugfix/docs/teste) | PR aprovado sem lint errors | Buddy + Tranquilão checklist |
| 4 | Segurança básica + docs | PR security checklist pass + README tocado | Tranquilão review |

**Skills mínimas** (TEAM-ROLES Jr): Git/PR · env boot · unit+AAA · zero lint · secrets/input validation · docs template.
**Anti-patterns**: commitar `.env` · mockar código interno (dublê faz a cena perigosa, não o ator principal) · PR gigante.
**Próximo nível**: trilha Mid quando conduzir 1 grill-me de colega (mentoring) + feature skeleton completa.
