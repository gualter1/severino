# Trilha Especialista — Segurança / Arquitetura / etc.

**Objetivo**: profundidade certificável num eixo, com ponte para os demais.

## Segurança (Kaspersky + Tranquilão)
- [ ] STRIDE completo de 1 fluxo crítico → threat model aprovado
- [ ] SAST/DAST no pipeline + triagem de 5 findings reais
- [ ] Compliance mapping (ex.: OWASP Top 10 / LLM Top 10) da feature

## Arquitetura (Niamaia)
- [ ] ADR de stack/decisão + Technology Radar note
- [ ] Deep-modules audit: imports só via entry-points (portaria, não janela do vizinho)

## Qualidade (Qualy)
- [ ] Mutation testing em 1 módulo + elevação de 1 gate
- [ ] Contract test consumer-driven + E2E crítico

## Frontend/DX (Turing)
- [ ] A11y AA em 1 fluxo + design tokens aplicados
- [ ] Feedback-loop CLI medido (build/test < alvo do projeto)

## Regra comum
Cada especialista deve **dar 1 aula de 15 min** (Guanabara grava/formata ❌/✅) para fechar o loop de aprendizado.
